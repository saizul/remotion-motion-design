# Motion Design with Code (Remotion)

Motion graphics and social-media videos (Reels, ads, explainers) built with [Remotion](https://remotion.dev), React and TypeScript.

```bash
npm install
npx remotion studio
npx remotion render <CompositionId> out/video.mp4
```
